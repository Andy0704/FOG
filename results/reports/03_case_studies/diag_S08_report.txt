ANALYSIS QUESTION: is S08's below-chance AUC most consistent with
  (a) label inversion / sensor mis-orientation (data issue), or
  (b) genuinely hard-but-valid data (keep, report honestly)?
==============================================================================
See reasoning below, built from sections 1-4 above. This is a recommendation
only -- no automatic fix or exclusion was applied.

Evidence AGAINST (a) sensor mis-orientation / label inversion:
  - Gravity-aligned axis (ankle_y) mean is 981.7 mg for S08 vs 989.5 (S05) and
    1011.9 (pool) -- same sign, same rough magnitude. A mounted-backwards or
    axis-swapped sensor would most plausibly show a SIGN FLIP or large offset
    on this axis (the axis nearest vertical / carrying the ~1g gravity
    component); none is seen. ankle_z is also same-sign, similar magnitude
    across S08/S05/pool. ankle_x shows a +176.8 mg offset vs pool's -10.9 mg,
    but this is well within 1 pool std (569 mg) -- ordinary inter-subject
    mounting-angle variance, not a flip.
  - The predicted-probability histograms (section 4b) do NOT show two
    well-separated clusters with the wrong one on top (which is what a clean
    label/axis inversion would produce). Both S08 label=0 and label=1
    distributions sit in the SAME narrow low-probability band (~0.15-0.30)
    with heavy overlap; label=1 is only marginally left-shifted vs label=0
    (mean_prob delta = -0.0127). Compare to S05 (healthy reference): same
    heavy overlap, but label=1 is shifted RIGHT of label=0, in the correct
    direction, also weakly. S08 looks like the SAME weak/noisy-signal regime
    as a normal subject, just with the weak bias pointing the wrong way --
    not a strong, cleanly-reversed signal.
  - Raw label composition is physiologically plausible: 14 discrete FoG
    events over ~201 s (S08R01), average ~14 s/event, in line with typical
    FoG episode durations reported in the literature and with S05's own event
    durations (66 events / 474 s, ~7 s/event). No signs of corrupted /
    scrambled labels (no impossible run lengths, no all-or-nothing episodes).

Evidence noted but NOT decisive for (a):
  - S08's raw-prob AUC (0.405) drops further from 0.5 after causal_median
    smoothing (0.360). Pure i.i.d. label noise would tend to regress toward
    0.5 under temporal smoothing, not move further away, so there IS a
    temporally-structured component to the mis-ranking. This is consistent
    with a systematic pattern -- but "systematic" does not require a data
    error; a real, consistent physiological difference produces the same
    signature (see below).
  - S08 has visibly lower signal variance than S05/pool on all 3 axes
    (std 89-244 mg vs pool's 300-570 mg), and only 1 recording file vs 2 for
    S05. Worth a calibration/gain sanity check as due diligence, but low
    variance alone does not indicate axis inversion or label corruption.

Evidence FOR (b) genuinely hard-but-valid data:
  - The raw-segment plot (4a) shows a plausible AKINETIC freezing pattern for
    S08: active gait-like oscillation on ankle_x/y before the labeled onset,
    then a markedly QUIETER, lower-amplitude segment during/after the FoG
    period, before oscillation resumes afterward. This is a recognized FoG
    phenotype (akinetic/motor-block freezing, as opposed to high-frequency
    leg-trembling freezing) -- i.e., the raw signal is doing something
    physiologically sensible at the labeled onset, not something that looks
    like a labeling glitch.
  - S08's positive-window fraction (0.28) is elevated vs the pool (mean 0.13,
    z=2.02) -- more FoG-labeled windows than typical, but not implausibly so,
    and consistent with an internally coherent (if unusually FoG-heavy)
    labeling for this subject.
  - Put together: the most likely mechanism is that the model, trained
    predominantly on subjects whose FoG events show HIGH-variance/trembling
    signatures, learned "increased signal variance -> FoG". For S08, whose
    FoG events are comparatively QUIET (akinetic), that learned rule fires
    backwards -- predicting LOW probability exactly when S08 is freezing.
    That produces a weak, temporally-consistent anti-correlation without any
    need for inverted labels or a flipped sensor axis.

CONCLUSION: (b) genuinely hard-but-valid data, not (a) label inversion or
sensor mis-orientation. No axis sign-flip or offset large enough to explain a
below-chance AUC was found; the predicted-probability distributions show weak
overlap with a mild wrong-direction bias rather than a clean reversal; and the
raw signal around the labeled FoG onset is physiologically consistent with a
recognized (akinetic) FoG phenotype. The most defensible read is a genuine
class-conditional domain-generalization failure -- the model's implicit
"FoG = high variance" heuristic, learned from the other 7 subjects, does not
transfer to S08's apparently akinetic freezing episodes.

RECOMMENDATION (not applied): keep S08 in the LOSO pool and report its
below-chance AUC honestly per CLAUDE.md S6 (do not drop it to inflate the
mean). Consider it a candidate for a short qualitative case study in the
write-up (trembling vs. akinetic FoG phenotypes as a generalization
challenge). If time permits, a low-cost due-diligence step would be
comparing S08's raw file byte-for-byte against the original Daphnet
distribution to rule out a corrupted local copy -- but nothing in this
analysis currently points to that being necessary.
